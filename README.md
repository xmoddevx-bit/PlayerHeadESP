# Player Head ESP

Clientseitige Fabric-Mod für Minecraft Java 1.21.11 von **Xmod_devX**.

Zeigt einen kleinen, cyanfarbenen Marker in Kopfgröße an der Kopfposition anderer Spieler, auch wenn Blöcke dazwischen liegen. Der Körper wird nicht hervorgehoben. Mit **H** schaltest du die Anzeige um (Taste in den Steuerungsoptionen änderbar).

## Installation

1. Fabric Loader für Minecraft 1.21.11 installieren.
2. Fabric API für 1.21.11 herunterladen.
3. Die Datei `PlayerHeadESP-1.0.0.jar` aus dem Repository herunterladen und zusammen mit Fabric API in den `mods`-Ordner legen.
4. Im Spiel mit **H** umschalten.

## Build

Mit JDK 21 oder neuer: `./gradlew build` (Windows: `gradlew.bat build`). Das fertige JAR liegt danach unter `build/libs/`.
